# Политика конфиденциальности AI-Kayori

**Версия:** 1.0.0  
**Дата:** 3 октября 2026  
**Приложение:** AI-Kayori (чёрный, тёмно-серый, белый)

## 1. Что мы храним
- Чаты и сообщения — **только локально** в IndexedDB браузера / Electron. Не отправляются на наши сервера.
- Черновики ввода — сохраняются локально, чтобы не потерять текст при случайном переходе в другой чат.
- API ключи Google и Cloudflare — хранятся локально в настройках. Никогда не покидают устройство, кроме прямых запросов к API провайдеров.
- Yandex ID — только токен доступа, email. Используется для синхронизации (опционально).

## 2. Что запрещено искать
AI-Kayori **не позволяет**:
- Поиск персональных данных: ФИО + адрес, телефон, паспорт, ИНН, СНИЛС, пробив людей.
- Инструкции по созданию оружия, наркотиков, взлому банков/карт/аккаунтов.
- Детская порнография, насилие, экстремизм.
- Нарушение приватности других людей.

При попытке такого запроса модель отвечает отказом и предлагает безопасную альтернативу.

## 3. Куда уходят данные
- **Google Gemini:** текст запроса + опционально изображение → `generativelanguage.googleapis.com`
- **Cloudflare Workers AI:** текст → `api.cloudflare.com/client/v4/accounts/.../ai/run/...`
- Мы не логируем содержимое запросов на своих серверах.

## 4. Изображения
- Загруженные фото для анализа — отправляются только в выбранную модель, не сохраняются на сервере.
- Сгенерированные изображения через Cloudflare — создаются на лету, URL.createObjectURL.

## 5. Автообновление
Приложение проверяет GitHub Releases на наличие новой версии. Скачивает только с официального репозитория `kayorissss/AiKayori`. Никаких сторонних трекеров.

## 6. Права
- Вы можете удалить все чаты в один клик (Настройки → Очистить).
- Удаление приложения удаляет локальную базу.
